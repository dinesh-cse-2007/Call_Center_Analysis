# 📞 Call Center Analysis

**Call Center Analysis** is a web-based application designed to analyze customer service interactions, monitor call center performance, and understand customer satisfaction. The system helps identify common customer complaints, analyze feedback sentiment, and track important call center performance metrics through an interactive dashboard.

## 🚀 Features

- 📊 **Performance Dashboard** – Displays call statistics and performance metrics.
- 📞 **Call Record Management** – Stores and manages call details.
- 😊 **Sentiment Analysis** – Classifies customer feedback as positive, negative, or neutral.
- 🔍 **Complaint Identification** – Identifies common customer problems and concerns.
- ⏱️ **Call Duration Analysis** – Tracks call duration and average handling time.
- ⭐ **Customer Satisfaction** – Analyzes customer ratings and feedback.
- 📈 **Data Visualization** – Displays statistics using charts and graphs.
- 🔎 **Search and Filter** – Finds specific call records and customer feedback.

## 🛠️ Technologies Used

- **HTML5** – Webpage structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Application logic and data processing
- **Chart.js** – Interactive charts and graphs
- **LocalStorage** – Client-side data storage

## ⚙️ How It Works

1. Enter or upload call records and customer feedback.
2. Process the available call data.
3. Analyze customer sentiment and identify common issues.
4. Calculate performance metrics such as call volume and average call duration.
5. Display the results in an interactive dashboard.

## 🎯 Objective

The main objective of this project is to help organizations understand customer needs, identify service problems, and improve call center efficiency through data analysis.
